# Code of Conduct

## 1. Our Pledge
We as SENA software analysis and development apprentices pledge to make participation in our project a harassment-free experience for everyone, regardless of age, background, or skill level.

## 2. Standards & Practices
- **Respect & Collaboration:** Maintain professional and technical communication.
- **Spec-Driven Governance:** Adhere strictly to the project architecture, data models, and repository structure rules.
- **Clean Code & SOLID:** Enforce high code readability and maintainability across all project contributions.
